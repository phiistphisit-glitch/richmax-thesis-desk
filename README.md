### วิธี Deploy (หัวหน้าทำครั้งเดียว)

1. เปิดชีตด้านบน → เมนู **Extensions** → **Apps Script**
2. ลบโค้ดเดิมใน `Code.gs` (ถ้ามี) แล้ววางทั้งไฟล์จาก repo: `apps-script/Code.gs`
3. กด **Deploy** → **New deployment** (หรือ Manage deployments → Edit → Version: New version ถ้าเคย Deploy แล้ว)
4. ชนิด: **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
5. Deploy แล้ว **คัดลอก URL ที่ลงท้าย `/exec`**
6. บอก Tony ว่า deployment URL คืออะไร (หรือส่ง Deployment ID) — จะใส่ใน `SHEETS_WEBAPP_URL` ใน `index.html` แล้ว push ขึ้น Pages

หลังใส่ URL แล้ว ทุกครั้งที่กดผลการตรวจ (ผ่าน / ต้องแก้ไข / ล้าง) หรือบันทึกข้อเสนอแนะ จะมีแถวใหม่ในชีตโดยอัตโนมัติ

ตรวจสุขภาพ: เปิด URL `/exec` ในเบราว์เซอร์ ควรได้ `{"ok":true,"service":"RICHMAX Thesis Desk - Review Log",...}`

## ประวัติเวอร์ชัน (ไม่ลบของเก่า)

ทุกครั้งที่ ดร.วิชิต หรือ พี่บิ๊ก กดผ่าน / ต้องแก้ไข / บันทึกข้อเสนอแนะ ระบบ**เพิ่มแถวใหม่**ในชีตเท่านั้น ไม่ลบและไม่เขียนทับแถวเก่า

เปิดชีตแล้วเรียงตามคอลัมน์ Timestamp หรือ Version เพื่อดูเวอร์ชันเก่าได้ทุกครั้ง

### กู้คืนเวอร์ชันเก่า (Restore link)

แต่ละแถวมีคอลัมน์ **Restore link** — กดแล้วเปิดโต๊ะตรวจพร้อมสถานะตอนนั้น (สถานะหัวข้อ · ติ๊กย่อหน้า · ข้อความโน้ต)

- สถานะถูกฝังในลิงก์เอง (`#restore=...`) เพราะหน้าเว็บอ่านชีตส่วนตัวไม่ได้
- กู้คืนแล้วจะ**เขียนทับสถานะในเครื่องสำหรับหัวข้อนั้น** และบันทึก local — **ไม่ลบแถวในชีต** (ยัง append-only)
- ถ้าโน้ตยาวมาก ลิงก์อาจตัดข้อความโน้ต (มีธง truncated) แต่สถานะหลักยังครบ

คอลัมน์ **State JSON** เก็บสำเนาเต็ม (สูงสุด ~4000 ตัวอักษร) สำหรับอ้างอิงในชีต
