## Google Sheet — บันทึกการตรวจทุกครั้ง

ชีต: [RICHMAX Thesis Desk - Review Log](https://docs.google.com/spreadsheets/d/1W_qCzD0Pw_3FgXxRy55KQDTAq7XcmBRf3N7GqqWRqzo/edit)

Token ในเว็บ: `richmax-td-2026` (ต้องตรงกับ `SHARED_TOKEN` ใน Apps Script)

ผู้ตรวจ 2 คน (เลือกตอนโหมดอาจารย์): **ดร.วิชิต** (= ผศ. ดร.วิชิต สุรดินทร์กูร อาจารย์ที่ปรึกษา) · **พี่บิ๊ก**  
ชีตบันทึกบทสนทนาตรวจระหว่างสองคนนี้เท่านั้น — แต่ละครั้งที่กดผลตรวจหรือบันทึกข้อเสนอแนะ = 1 เทิร์นของผู้ที่เลือกไว้  
โหมดนักศึกษายังใช้ในแอปได้ แต่**ไม่**ถูกส่งเข้าชีต

### วิธีติดตั้งบน iPad (ทำครั้งแรก)

ใช้ Safari บน iPad (ไม่ใช่แอป Google Sheets) และล็อกอินบัญชี Google ที่เป็นเจ้าของชีต

1. เปิดลิงก์ชีตนี้ใน Safari:
   https://docs.google.com/spreadsheets/d/1W_qCzD0Pw_3FgXxRy55KQDTAq7XcmBRf3N7GqqWRqzo/edit
   - ถ้า Safari เด้งไปเปิดแอป Google Sheets ให้กดค้างที่ลิงก์ → เลือก **เปิดในแท็บใหม่** หรือกดปุ่ม **aA** บนแถบที่อยู่ → **ขอเว็บไซต์เดสก์ท็อป** (Request Desktop Website)
2. ในชีต กดเมนู **Extensions** (ส่วนขยาย) → **Apps Script** — จะเปิดแท็บใหม่เป็นหน้าเขียนโค้ด
3. ทางซ้ายกดไฟล์ **Code.gs** แล้ว **ลบโค้ดเก่าทั้งหมด**:
   - แตะ 1 ครั้งในช่องโค้ด → กดค้างจนมีเมนูขึ้น → **Select All** (เลือกทั้งหมด) → กด **Delete** (หรือปุ่มลบบนแป้นพิมพ์)
   - ถ้าไม่มีเมนู Select All: กดค้างที่คำแรกบรรทัดบนสุด แล้วลากจุดจับสีฟ้าลงไปจนสุดบรรทัดล่างสุด → กดลบ
   - ตรวจว่าช่องโค้ดว่างจริง ไม่มีโค้ดเก่าเหลือ
4. เปิดไฟล์ใหม่ใน repo: [apps-script/Code.gs](apps-script/Code.gs) → กดปุ่ม **Raw** → กดค้าง → **Select All** → **Copy**
   แล้วกลับไปแท็บ Apps Script → แตะในช่องโค้ดที่ว่าง → กดค้าง → **Paste** (วาง)
5. กดรูปแผ่นดิสก์ **Save** (บันทึก) ด้านบน
6. กด **Deploy** (การทำให้ใช้งานได้) มุมขวาบน → **New deployment** (การทำให้ใช้งานได้รายการใหม่)
7. กดรูปเฟือง ⚙ ข้าง "Select type" → เลือก **Web app** (เว็บแอป)
   - Execute as (เรียกใช้ในฐานะ): **Me** (ตัวเอง)
   - Who has access (ผู้มีสิทธิ์เข้าถึง): **Anyone** (ทุกคน)
8. กด **Deploy** — ครั้งแรก Google จะถามสิทธิ์: กด **Authorize access** → เลือกบัญชี → ถ้าขึ้น "Google hasn't verified this app" ให้กด **Advanced** → **Go to … (unsafe)** → **Allow** (เป็นสคริปต์ของเราเอง)
9. จะได้ลิงก์ **Web app URL** ที่ลงท้ายด้วย **/exec** → กด **Copy**
10. **ส่งลิงก์ /exec นี้ให้ Tony** (ทาง LINE หรืออีเมล) — Tony จะใส่ลงใน `SHEETS_WEBAPP_URL` ใน `index.html` แล้วขึ้นเว็บให้

> ตอนนี้ `SHEETS_WEBAPP_URL` ยังว่างอยู่ (ตั้งใจ) จนกว่าจะได้ลิงก์ /exec จริง — ระหว่างนี้แอปยังใช้ได้ แต่ยังไม่ส่งข้อมูลเข้าชีต

### ถ้าเคย Deploy แล้ว และมี Code.gs ใหม่ (อัปเดต)

ทำข้อ 1–5 เหมือนเดิม (ลบโค้ดเก่า → วางโค้ดใหม่ → Save) แล้ว:

1. กด **Deploy** → **Manage deployments** (จัดการการทำให้ใช้งานได้)
2. เลือกรายการ Web app เดิม → กดรูปดินสอ ✏️ **Edit**
3. ช่อง **Version** เลือก **New version** (เวอร์ชันใหม่)
4. กด **Deploy**

แบบนี้ลิงก์ /exec **ยังเป็นลิงก์เดิม** ไม่ต้องส่งใหม่ให้ Tony
(อย่ากด New deployment ซ้ำ เพราะจะได้ลิงก์ /exec ใหม่ ต้องส่งให้ Tony แก้เว็บอีกรอบ)

### ตรวจว่าใช้ได้

- เปิดลิงก์ /exec ใน Safari ควรเห็นข้อความประมาณ `{"ok":true,"service":"RICHMAX Thesis Desk - Review Log",...}`
- หลัง Tony ใส่ลิงก์แล้ว: เปิดโต๊ะตรวจ → เลือกโหมด **อาจารย์** → เลือกผู้ตรวจ (**ดร.วิชิต** หรือ **พี่บิ๊ก**) → กดผ่าน / ต้องแก้ไข / บันทึกข้อเสนอแนะ → ในชีตจะมีแถวใหม่เพิ่มขึ้นทุกครั้ง
- ทุกครั้งที่กด ผ่าน / ต้องแก้ไข / ล้างผล / ติ๊กย่อหน้า / บันทึกข้อเสนอแนะ = 1 แถวใหม่ (การส่งเข้าชีตทำเบื้องหลัง หน้าจอไม่ต้องรอ)
- ถ้าชีตมีหัวตารางแบบเก่าอยู่แล้ว สคริปต์จะเพิ่มคอลัมน์ที่ขาด (Version / State JSON / Restore link) ต่อท้ายให้เอง ไม่ย้ายและไม่ลบของเดิม

## ประวัติเวอร์ชัน (ไม่ลบของเก่า)

ทุกครั้งที่ ดร.วิชิต หรือ พี่บิ๊ก กดผ่าน / ต้องแก้ไข / บันทึกข้อเสนอแนะ ระบบ**เพิ่มแถวใหม่**ในชีตเท่านั้น ไม่ลบและไม่เขียนทับแถวเก่า

เปิดชีตแล้วเรียงตามคอลัมน์ Timestamp หรือ Version เพื่อดูเวอร์ชันเก่าได้ทุกครั้ง

### กู้คืนเวอร์ชันเก่า (Restore link)

แต่ละแถวมีคอลัมน์ **Restore link** — กดแล้วเปิดโต๊ะตรวจพร้อมสถานะตอนนั้น (สถานะหัวข้อ · ติ๊กย่อหน้า · ข้อความโน้ต)

- สถานะถูกฝังในลิงก์เอง (`#restore=...`) เพราะหน้าเว็บอ่านชีตส่วนตัวไม่ได้
- กดแล้วหน้าเว็บจะขึ้นว่า **"โหลดเวอร์ชันเก่าแล้ว"** และเปิดหัวข้อนั้นให้ — ผลตรวจ (ผ่าน/ต้องแก้ไข) และติ๊กรายย่อหน้ากลับมาตามเวอร์ชันนั้น ข้อความโน้ตจะอยู่ในช่องข้อเสนอแนะ (ยังไม่บันทึก กดบันทึกเองถ้าต้องการ)
- เปลี่ยนเฉพาะในเครื่องที่เปิด — **ไม่ส่งอะไรเข้าชีต ไม่ลบแถวในชีต** (ยังเพิ่มอย่างเดียว) และไม่เปลี่ยนชื่อผู้ตรวจที่เลือกไว้ในเครื่อง
- ลิงก์ยาวไม่เกิน 2000 ตัวอักษร ถ้าโน้ตยาวมาก ลิงก์จะตัดข้อความโน้ตบางส่วน แต่ผลตรวจยังครบ (ฉบับเต็มดูได้ในคอลัมน์ State JSON)

คอลัมน์ **State JSON** เก็บสำเนาเต็ม (สูงสุด ~4000 ตัวอักษร) สำหรับอ้างอิงในชีต
